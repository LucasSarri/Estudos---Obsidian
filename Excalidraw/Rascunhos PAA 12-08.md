## Text Elements
Entrada
Uma sequência de n >= 1 números {a1, a2, ..., an}

Saída
Um valor max E {a1, a2, ..., an}, tal que max >= ai para i = 1, 2, ..., an ^wX5uoyoD

MAXIMO (A)
    max = A[1];
    for j = 2 to A.length
        if A[j] > max
            max = A[j];
    return max ^AP9PZRhN

Invariante 
max contém o maior valor de A[1..i-1].

Inicialização
Antes da primeira iteração i = 2 e max = A[1].
Então max é o maior valor de A[1]

Manutenção
Assumindo que a invariante é verdadeira antes da iteração i, então max contém o maior valor de A[1..i-1]. 
Se a condição A[i] > max for verdadeira, então A[i] é o maior valor de A[1..i] e o valor max é atualizado para A[i], caso contrário max não é alterado. 
Em ambos os casos max contém o maior valor de A[1..i], incrementando i para a próxima iteração preserva a invariante.

Término
Quando o laço termina temos i = n + 1.
Substituindo i por n + 1 no enunciado da invariante temos que max é o maior valor de A[1..(n+1)-1] = A[1..n]. Logo, max é o maior valor de A e o algoritmo está correto.
 ^RNlfl6Dn

MINIMO (A, n)
    min= A[1]
    for i = 2 to n
        if A[i] < min
            min= A[i]
    return min ^OWUc69Un

Selection-sort (A, n)
    for i = 1 to n -1
        k = i
        for j = i + 1 to n
            if A[j] < A[k]
                k = j
        troca(A, i, k) 
         ^OMWlC8Kg

Invariante 
Laço interno: A[min] contém o menor elemento de A[i..j-1]
Laço externo: o subarranjo A[1..i-1] consiste dos i-1 menores elementos do arranjo A[1..n] e, este subarranjo está ordenado.

Inicialização
Quando i = 1, o subarranjo A está vazio e, portanto, o invariante é trivialmente verdadeiro.

Manutenção
Considere uma iteração i qualquer e assuma que o invariante é verdadeiro no início desta iteração. Executando as linhas 2 a 5 do corpo do laço, min conterá a posição do menor valor do arranjo A[1..n]. A linha 6 faz a troca entre os elementos na posição 1 e min. Assim, se A[1..i-1] continha os menores valores do arranjo A[1..n] em ordem e agora A[i] contém o menor valor de A[i..n], então é possível afirmar que A[1..i] contém os menores valores do arranjo A[1..n] em ordem (e o invariante é verdadeiro para a próxima iteração).

Término
Quando i = n, o subarranjo A[1..n-1] consiste dos n-1 menores elementos do arranjo A[1..n] em ordem. Como A[n] é o maior dos elementos e está na posição correta, então o arranjo inteiro está ordenado.
 ^DqiCEAlk

Troca (A, i, k)
    aux = A[i]
    A[i] = A[k]
    A[k] = aux
