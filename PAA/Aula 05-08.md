
# Problema computacional
É uma relação entre um conjunto de entradas e de saídas ou um conjunto de entradas e instâncias. Especifica em termos gerais o relacionamento entre a entrada e a saída desejada.
Uma entrada é um valor ou sequência de valores conhecidos, uma saída é um valor que será computado a partir da entrada.

# Algoritmo
Um algoritmo é sequência finita de instruções/comandos não ambíguas tal que sua execução sempre termina. Toma nenhum, um valor ou um conjunto de valores como entrada. Retorna nenhum, um valor ou conjunto de valores como saída. É usado para realizar computações e resolver um problema computacional.

## Análise de algoritmos
- Simplicidade: um algoritmo é simples se puder ser facilmente entendido, implementado e mantido.
- Corretude/correção (eficácia): um algoritmo é correto para toda entrada válida ele termina com a saída correta, o algoritmo resolve o problema computacional relacionado.
- Eficiência: medida quantitativa inversa da quantidade de recursos como tempo de processamento e espaço de memória requeridos para a execução do algoritmo.
