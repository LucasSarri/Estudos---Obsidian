#banco_de_dados

Um estado ou instante do [[Bancos de Dados|banco de dados]] apresenta os **dados** de um [[Bancos de Dados|banco de dados]] em um determinado momento no tempo.

# Estados de um Banco de dados
Abaixo iremos apresentar alguns dos estados comuns de um  [[Bancos de Dados|banco de dados]] .

## Estado Inicial
Este é o estado onde o  [[Bancos de Dados|banco de dados]]  esta populado ou carregado com os **dados** iniciais.

## Estado Válido
Este estado é onde o [[Bancos de Dados|banco de dados]]  satisfaz a estrutura e as restrições especificadas no [[Esquemas|esquema]].

## Estado Inválido
Este estado é onde o [[Bancos de Dados|banco de dados]] não obedece todas as restrições que foram definidas.
