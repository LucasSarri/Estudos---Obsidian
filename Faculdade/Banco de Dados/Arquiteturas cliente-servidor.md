#banco_de_dados

# Servidores com funcionalidades específicas

## Servidor de arquivos
Mantém os arquivos das máquinas clientes.

## Servidor de impressão
Um servidor que é conectado à várias impressoras, onde todas as solicitações de impressão feitas pelos clientes são encaminhadas para o servidor.

## Máquinas cliente
Oferecem ao usuário **interfaces** apropriadas para utilizar esses servidores, poder de processamento local para executar aplicações locais.

## Cliente
Máquina que oferece capacidades de **interface** com o usuário e processamento local

## Servidor
Máquina que oferece serviços às máquinas [[Arquiteturas cliente-servidor#Cliente|cliente]], como acesso a arquivos, impressão, arquivamento ou acesso a [[Bancos de Dados|banco de dados]].

## Servidor de aplicação ou servidor **Web**
Acrescenta uma camada intermediária entre o [[Arquiteturas cliente-servidor#Cliente|cliente]] e o servidor de [Bancos de Dados|banco de dados]], executa programas de aplicação e armazena regras de negócios.
