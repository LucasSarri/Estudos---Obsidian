* CRUD de controle de horas: sistema onde são cadastrados projetos, e para cada projeto é possível realizar o registro das entradas e saídas de horas (registra data e horário de início e data e horário de termino). O sistema contabiliza e gera relatórios de horas trabalhadas por projeto.
* CRUD de ranking de filmes: nesse projeto o sistema vai consumir uma API chamada The Movie Database, onde o usuário poderá localizar os filmes que serão retornados pela API e realizar um registro de nota, dar uma uma review e colocar no seu ranking de filmes.
* Encurtador de URL: o usuário vai cadastrar uma URL e o sistema vai gerar uma URL encurtada, e quando a URL encurtada for acessada o sistema vai redirecionar para a URL cadastrada. Também é interessante computar quantas vezes cada URL foi acessada e gerar as estatísticas.
* Criar um sistema com autenticação:
	* Autenticação simples com token ou sessão
	* Autenticação de 2 fatores, com email ou SMS
	* Auth 2.0 utilizando um token de permissões
