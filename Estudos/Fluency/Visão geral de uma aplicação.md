# Qual a diferença entre front-end e back-end?
O front-end: O desenvolvedor front-end resumidamente é responsável em desenvolver à parte do aplicativo ou site que interage diretamente com o usuário.
O back-end: O desenvolvedor back-end resumidamente é responsável em desenvolver à parte do aplicativo ou site que opera nos bastidores, gerenciando a lógica de negócios, banco de dados e comunicação com o servidor.

# O que faz um desenvolvedor back-end?
Um desenvolvedor back-end cria e mantém a parte do servidor de aplicativos e sites. Ele é responsável pela lógica do sistema, gestão de bancos de dados, desenvolvimento de APIs, segurança dos dados e otimização de desempenho. Trabalha em conjunto com os desenvolvedores front-end para garantir a integração eficaz entre a interface do usuário e a funcionalidade do servidor.

# Tecnologias relacionadas com o back-end
Os desenvolvedores back-end podem acabar trabalhando com diferentes linguagens de programação, como: Node.JS, Java, Ruby, Python, PHP, Go, entre outras.

E quando se está trabalhando com banco de dados você pode acabar se deparando com diferentes paradigmas de modelagem, como bancos relacionais e não relacionais (NoSQL).

Também é comum que você precise conhecer alguns protocolos de comunicação como o HTTP e forma de representação de dados para tráfego de informação como o JSON.
