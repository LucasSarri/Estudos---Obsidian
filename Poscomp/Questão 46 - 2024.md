# Questão 
Analise as assertivas abaixo sobre estruturas em linguagens de programação:
1. Uma estrutura é um conjunto de uma ou mais variáveis agrupadas sob único nome, de forma a facilitar a sua referência
2. A declaração de uma estrutura corresponde unicamente à definição de um novo tipo (isto é, da sua estrutura), e não à declaração de variáveis do tipo da estrutura
3. Uma estrutura pode conter, na sua definição, variáveis simples, vetores, ponteiros ou mesmo outras estruturas
4. As estruturas permitem agrupar diversos componentes em única variável, que podem ser definidos com tipos distintos

# Explicação
Sobre a assertiva 1, ela é correta pois uma estrutura permite agrupar várias variáveis (de tipos possivelmente diferente) sob um nome comum. Exemplo:
struct Pessoa {
    char nome[50];
    int idade;
    float altura;
};
Aqui, nome, idade e altura são agrupados sob a estrutura Pessoa.

A assertiva 2 é correta também pois a declaração de uma estrutura define o molde (tipo) da estrutura onde nenhuma variável é criada ainda. Exemplo:
struct Produto {
    int codigo;
    float preco;
};
Aqui estamos apenas definindo a estrutura Produto, nenhuma variável é criada ainda.

A assertiva 3 é verdadeira, pois as estruturas são bastante flexíveis e permitem inserir nelas variáveis simples, vetores, ponteiros e outras estruturas.

A assertiva 4 também é verdadeira, pois resume muito bem o propósito de uma estrutura, a principal vantagem é justamente essa, agrupar dados heterogêneos sob uma única entidade. Exemplo: 
struct Carro {
    char modelo[50];   // string
    int ano;           // inteiro
    float preco;       // real
};

# Resposta
Desta forma todas as assertivas estão corretas.
Resposta: E) I, II, III e IV
