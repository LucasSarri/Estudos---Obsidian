# Questão 
Sobre os tipos de dados básicos, assinale a alternativa correta:
1. As variáveis do tipo inteiro são utilizadas para armazenar valores que pertencem ao conjunto de números naturais (sem parte fracionária) positivos e negativos
2. O tipo caractere permite armazenar strings ou conjuntos de caracteres em uma variável do tipo caracter
3. Por padrão, uma variável do tipo inteiro admite somente valores positivos. Caso deseje que a variável contenha valores negativos, é necessário utilizar o comandeo da linguagem de programação para incluir sinal
4. As variáveis do tipo vetor são utilizadas para armazenar valores numéricos com parte fracionária
5. O conjunto de operações disponível para o tipo caractere inclui soma, subtração, multiplicação, divisão inteira e resto da divisão

# Explicação
A alternativa 1 está quase correta, os números naturais citados pela questão são não-negativos {0, 1, 2, 3, ...}, já o tipo inteiro das linguagens de programação abrange números positivos e negativos, o que corresponde ao conjunto dos inteiros e não dos naturais.

A alternativa 2 está incorreta, pois o tipo char armazena apenas um caracter (como `'A'`, `'z'`, `'0'`), para armazenar strings (conjuntos de caracteres) usa-se ou um vetor do tipo char (ex: char nome[50]) ou o tipo string.

A alternativa 3 está errada, pois variáveis inteiras já consideram valores positivos e negativos por padrão e se você quiser considerar apenas o número sem o sinal você deve usar o unsigned int.

A alternativa 4 está errada por dois motivos, um vetor não está relacionado apenas a valores fracionários, ele é um tipo de estrutura de dados que armazena vários elementos do mesmo tipo, sejam eles int, float, char, etc.

A alternativa 5 está errada, pois o tipo char pode participar de operações aritméticas apenas porque é representado como um número (código ASCII ou Unicode), mas não é o objetivo dele. Operações como soma ou subtração são possíveis (ex: `'A' + 1` → `'B'`), mas multiplicação, divisão e módulo não são operações padrão de manipulação de caracteres.

# Resposta
Dentre as alternativas, a 1 é a que está quase correta apenas estando errado a questão da confusão entre números naturais e inteiros.
