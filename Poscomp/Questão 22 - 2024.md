# Questão 
Qual é o objetivo da análise assintótica de algoritmos?
1. Analisar conjuntamente o pior caso e o caso médio de um algoritmo
2. Analisar o desempenho do algoritmo para entradas muito pequenas
3. Determinar o desempenho do algoritmo para todas as possíveis entradas
4. Analisar o desempenho do algoritmo para entradas médias
5. Analisar o comportamento do algoritmo à medida que o tamanho da entrada aumenta indefinidamente

# Explicação
A análise assintótica busca avaliar o crescimento do tempo de execução (ou uso de memória) de um algoritmo em função do tamanho da entrada n, quando n tende ao infinito. Ele ignora detalhes melhores como constantes e foca na ordem de crescimento: por exemplo: O(n), O(n^2), O(log ⁡n), etc.

# Resposta
A alternativa 1 está errada, pois a analise assintótica pode ser feita para o melhor, o pior ou o caso médio, mas cada uma separadamente. Ela não consegue analisar mais de um por vez.
A alternativa 2 está errada, pois a análise assintótica ignora entradas pequenas, focando no comportamento quando a entrada cresce muito.
A alternativa 3 está errada, pois a análise assintótica foca no comportamento geral com base no tamanho da entrada, não em cada entrada individual.
A alternativa 4 está errada, pois se refere a um tipo específico de análise assintótica, mas não é o objetivo geral. Ela pode ser usada para o melhor, o pior ou caso médio, mas seu foco não é entradas médias.
A alternativa 5 está correta, é exatamente a definição clássica de análise assintótica, tendo o foco em como o algoritmo cresce em complexidade quando o tamanho de n tende ao infinito.


Resposta: E) Analisar o comportamento do algoritmo à medida que o tamanho da entrada aumenta indefinidamente
