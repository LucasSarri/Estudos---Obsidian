
# 2 - DIDACTICAL CONCEPT
## 2.1 Objetivos de Aprendizagem
A estrutura fundamental de uma _Visual Novel_ (VN) é sempre uma história [6]. De acordo com a metodologia de Salazar, Nakajima e Alexandrova [21], quando utilizadas em contexto educacional, as VNs devem focar em um tópico específico de ensino. Por esse motivo, foi desenvolvida uma história sobre o **Modelo Cascata (Waterfall Model - WM)** como exemplo da utilização de VNs no ensino de Engenharia de Software. O procedimento descrito neste trabalho também pode ser aplicado a outros tópicos da área.

## 2.2 Implementação na Disciplina
Os arquivos executáveis gerados pela VN podem ser disponibilizados aos estudantes por meio de um curso online na plataforma **Moodle** [17], onde já se encontram todos os materiais da disciplina de Engenharia de Software.

A VN é disponibilizada como executáveis para Windows, Linux e MacOS. Seu foco é reforçar conteúdos já apresentados anteriormente em aula, funcionando como um **material complementar** de uma unidade de ensino existente.

Os autores planejam utilizá-la como parte dos exercícios da disciplina de Engenharia de Software da Universidade de Ciências Aplicadas de Kempten. Durante a atividade, os estudantes poderão baixar o aplicativo e avançar pela narrativa. Caso surjam dúvidas, elas poderão ser respondidas pelo professor ou por uma funcionalidade que permite ao estudante retornar a uma parte específica do vídeo da aula caso não consiga resolver um dos exercícios.

## 2.4 Cenário de Aprendizagem Desenvolvido
Para criar um ambiente com o qual os estudantes pudessem se identificar, o protagonista da história é um estudante que conseguiu um estágio na empresa fictícia **SwegEd** (nome inspirado no canal do YouTube onde o vídeo educacional utilizado foi publicado).

O jogador vivencia a Visual Novel em **primeira pessoa**.

Durante o estágio, o protagonista e dois colegas precisam desenvolver um aplicativo móvel capaz de exibir o nível de café restante na cafeteira dos desenvolvedores.

Esse projeto possui características específicas que justificam a utilização do Modelo Cascata:

- O projeto é pequeno;
- O projeto e seus objetivos são fáceis de compreender;
- O projeto é autocontido;
- Os marcos do projeto são fáceis de definir;
- Os requisitos são definidos apenas uma vez e não sofrerão alterações durante o desenvolvimento.

Segundo o vídeo utilizado como base, essas características tornam o uso do Modelo Cascata apropriado [11].

A história é composta por **dez cenas**. Para cada cena foram definidos objetivos de aprendizagem específicos, com exceção das cenas 0 e 1, que servem como introdução e explicação do projeto de estágio.
