# Paradigma DBC (Component-Based Software Engineering)
O DBC é o processo de definição, implantação e integração de componentes independentes, que não são firmemente acoplados ao sistema.

## Ecosistema DBC
1. Componentes Independentes: especificados estritamente por suas interfaces.
2. Padrões de implementações: Regras universais para facilitar a integração.
3. Middlewares: Infraestrutura para apoiar a comunicação e integração.
4. Processo Orientado à Reutilização: Uma mudança de mentalidade no ciclo de desenvolvimento.

# Princípios Fundamentais de Engenharia de Software
O DBC baseia-se no princípio clássico de Dividir para Conquistar, quebrando problemas complexos em pedaços menores e combiná-los logicamente.
- Independência Operacional: componentes não interferem uns nos outros.
- Ocultação: Implementações internas são totalmente ocultadas.
- Comunicação Padronizada: Ocorre exclusivamente por meio de interfaces bem definidas.
- Compartilhamento de Plataforma: Plataformas comuns reduzem drasticamente os custos.
