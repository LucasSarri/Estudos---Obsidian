# Indução matemática
Princípio fraco da indução matemática: ==se== sentença P(b) é verdadeira e a sentença P(n-1) => P(n) é verdadeira para todo n > b, ==então== P(n) é verdadeira para todos os inteiros n >= b.

# Correção de algoritmos recursivos
Dado um problema de n elementos no vetor A, encontre o máximo.

```
MAXIMO (A[], n)
	if n = 1 then
		return A[1]
	return max(MAXIMO(A[], n-1), A[n])
```
