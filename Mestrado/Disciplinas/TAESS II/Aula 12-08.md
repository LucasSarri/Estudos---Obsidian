# Otimização em Engenharia de Software
Problemas complexos, com grande espaço de busca e ausência de solução ótima conhecida. Exemplos:
- Planejamento de Releases
- Estimativa de Custos
- Alocação de Pessoal
- Otimização de Projeto de Arquitetura de Software
- Otimização de Código Fonte
- Geração, Seleção e Priorização de Casos de Teste

## Como aplicar ?
Escolha de uma representação para as soluções do problema. Definição da(s) função(ões) de avaliação e das restrições do problema. Escolha e aplicação de algoritmos de busca.

## Projeto de Arquitetura
Representa a ligação (crítica) entre requisitos e implementação. (Garlan, 2014)
Sua importância tem crescido significativamente devido à demanda de desenvolvimento de software de alta complexidade e requisitos de qualidade desafiadores. Exemplo:
- Software Embutido
- Software Concorrente
- Linha de Produto de Software

Exemplos de decisões complexas:
- Como decompor o sistema em subsistemas mais fáceis de gerenciar?
- Que estilos arquiteturais/padrões de projeto são apropriados ?
- Como projetar a topologia de hardware mais apropriada para o sistema de software ?
- Como distribuir os componentes de software nos recursos de hardware disponíveis visando minimizar custo, maximizar desempenho e satisfazer todas as restrições?
