# Temas de interesse
- Aplicação de inteligência computacional para o desenvolvimento de software: projeto de software, linha de produto de software, teste de software,evolução de software e refatoração
- Evolução de software com microsserviços
- Ensino de Engenharia de Software: metodologias ativas, uso de projetos de software livre e neurodiversidade em engenharia de software

# Sobre a disciplina
- Estudar técnicas de engenharia de software baseada em busca e desenvolver uma solução automatizada usando tais técnicas para um problema de Engenharia de Software.
