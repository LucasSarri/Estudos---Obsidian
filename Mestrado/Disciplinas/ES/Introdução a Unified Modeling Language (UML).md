# UML - Unified Modeling Language
Linguagem visual para especificação (modelagem) de sistemas orientados a objetos, mas a UML é de propósito geral podendo ser usada nas seguintes etapas:
- Análise
- Projeto
- Implementação
- Testes

A UML privilegia a descrição de um sistema segundo três perspectivas:
- Dados (estrutural): diagrama de classes
- Operações (funcional):

Desde que foi aprovada pela OMG, a UML tem tido grande aceitação pela comunidade de desenvolvedores de sistemas. Só aprender a notação UML não é tudo, é importante criar projetos pensando em objetos.

Os artefatos de software construídos através da UML evoluem à medida que as iterações são realizadas.

# Diagramas UML
- Diagramas Estáticos: modelam a estrutura do código
- Diagramas Dinâmicos: modelam a execução do código (comportamento do sistema)

Um processo de desenvolvimento que utilize a UML como linguagem de modelagem envolve a criação de diversos documentos, esses documentos podem ser textuais ou gráficos.
