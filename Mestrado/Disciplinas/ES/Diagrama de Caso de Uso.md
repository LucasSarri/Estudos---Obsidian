#engenharia-de-software 

[[Engenharia de Software - UML|Desenhos da aula 31-03-2026]]

Permite representar as funções esperadas do sistema, sem mencionar como elas devem ser executadas.

Um diagrama de casos de uso mostra o relacionamento entre os atores e casos de uso dentro de um sistema

Um caso de uso representa uma funcionalidade do sistema. Ele é representado por uma elipse contendo o nome do caso de uso.

Um ator é um agente externo que interage com o sistema.

# Atores
Um ator estimula o sistema com eventos de entrada ou recebe alguma saída dele.
- Pessoas
- Organizações
- Outros sistemas
- Equipamentos

# Casos de uso
Um caso de uso é sempre iniciado por um estímulo de um ator.

# Construção do diagrama UML
- Em sistemas pequenos ou médios pode ser criado um único DCU
