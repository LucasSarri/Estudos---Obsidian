#engenharia-de-software

# Definições básicas
- Sistema: um conjunto integrado de entidades funcionais que interagem entre si e são interdependentes
- Sistema computacional: sistema cujas entidades funcionais podem ser basicamente classificadas como hardware ou software
- Software
	- Conjunto de instruções (programas de computador) que, quando executadas, produzem a função e o desempenho desejados
	- Documentos que descrevem a operação e uso dos programas
	- Programas de computador e artefatos associados
	- Produtos de software podem ser:
		- Genéricos: desenvolvidos para serem vendidos para uma grande variedade de clientes (Excel, Word, etc)
		- Personalizados: desenvolvidos para um único cliente de acordo com as suas especificações
- Engenharia de Software: é uma disciplina relacionada com todos os aspectos da produção de software. Conjunto de processos, métodos, técnicas e ferramentas que ajudam a produzir software com maior qualidade e com menor custo.

# Características da Engenharia de Software
- O desenvolvimento de software requer a cooperação regular entre as pessoas, com o trabalho em paralelo de várias pessoas, torna-se essencial a distribuição das tarefas, a comunicação, etc.
- O software deve suportar de forma efetiva as necessidades de seus usuários.
- Na Engenharia de Software, membros de uma cultura criam artefatos para membros de outras culturas. Os engenheiros de software normalmente não são especialistas no domínio do problema.

# O que é processo de software?
- Um conjunto estruturado de atividades, práticas, artefatos e ferramentas necessários para o desenvolvimento de um sistema de software.
- Elementos fundamentais:
	- Métodos: prescrevem os detalhes sobre como fazer para construir o software
	- Ferramentas: dão suporte automatizado aos métodos
	- Procedimentos: são a ligação entre os métodos e as ferramentas
